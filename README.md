# Ôn tập Xoa bóp bấm huyệt

Website trắc nghiệm responsive gồm 60 câu, chạy trực tiếp trên trình duyệt, không cần cài đặt hay backend.

## Tính năng
- Làm trắc nghiệm từng câu, kiểm tra đúng/sai và xem đáp án đúng.
- Tự tính điểm và xem kết quả.
- Chế độ **Xem 60 câu & đáp án** để xem toàn bộ đề cùng đáp án đúng trên một trang.
- Tìm nhanh câu hỏi trong danh sách đáp án.
- Giao diện tương thích điện thoại và máy tính.

## Chạy
Mở `index.html` bằng trình duyệt. `questions.js` phải nằm cùng thư mục.

## Đăng lên GitHub Pages
1. Tạo repository mới trên GitHub.
2. Upload `index.html`, `questions.js`, `README.md` lên thư mục gốc.
3. Vào **Settings → Pages**.
4. Chọn **Deploy from a branch**, branch `main`, folder `/ (root)`, rồi Save.
